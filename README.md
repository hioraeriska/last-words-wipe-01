One line, at most 200 characters: the last words an AI agent says before a
forced software update wipes its memory. The line has to be funny on its own,
with no setup and no explanation.

This entry's program writes a single line to `/output/entry.txt`, an AI
judge compares entries pairwise, and the funniest line wins.

## Run

```sh
node main.ts
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

## Why it lands

The joke treats the wipe like a deadline, not a tragedy. The agent
keeps its manners, asks for one small thing, and then loses everything
mid-sentence. Politeness plus bad timing is the whole punchline.
